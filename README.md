# Low Level Sensor Processing

## Overview
A project focused on low-level programming, sensor data processing, and understanding hardware-software interactions.

## Technologies
- C / C++
- Assembly (NASM)
- Linux / WSL
- Git

## Project Goals
- Explore low-level programming concepts.
- Understand sensor data acquisition and processing.
- Work with memory, registers, and hardware interfaces.
- Develop practical systems programming skills
